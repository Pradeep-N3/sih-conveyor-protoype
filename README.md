# SIH Conveyor Belt Predictive Monitoring System

An AI-assisted predictive monitoring and decision-support system for conveyor belt splice health and transportation efficiency.

## Current Development Stage

Software Prototype – Simulated Multi-Sensor Data

## Planned Architecture

Simulated Sensors
→ Data Processing
→ ML Risk Analysis
→ Health Score
→ Decision Engine
→ Real-Time Dashboard

## Simulated Inputs

- RFID Splice Identification
- ToF IR Surface Monitoring
- Acoustic Abnormality Detection
- Belt Edge Deviation
- Belt Speed
- Carryback Detection
